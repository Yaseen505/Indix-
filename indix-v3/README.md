ראו `supabase/SETUP-HE.md`. כשממלאים את `config.js`, המערכת עוברת למצב ענן: כניסה עם מייל וסיסמה, נתונים משותפים לכל המכשירים בזמן אמת, תמונות ב-Storage, הרשאות שנאכפות בשרת, ועבודה גם בלי קליטה (הנתונים נשמרים במכשיר ונשלחים כשהחיבור חוזר).
